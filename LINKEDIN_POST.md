# Post LinkedIn — CheckPro 2.0

Finalizei uma nova etapa do CheckPro 2.0, uma aplicação web desenvolvida para digitalizar checklists técnicos e inspeções de campo.

A ideia do projeto nasceu de uma necessidade comum em ambientes industriais: reduzir o uso de formulários manuais, melhorar a rastreabilidade das inspeções e transformar coletas técnicas em dados mais úteis para manutenção, PCM e gestão.

Nesta versão, a aplicação conta com:

- Login demonstrativo por perfil: Gestor, PCM e Eletricista
- Dashboard com indicadores operacionais
- Checklist digital por setor e equipamento
- Cadastro de parâmetros técnicos por equipamento
- Análise automática de limites de corrente e temperatura
- Geração automática de não conformidades
- Histórico de inspeções
- Exportação para Excel com abas de checklists, não conformidades e resumo
- Deploy na Vercel

Tecnologias utilizadas:
React, Vite, JavaScript, LocalStorage, XLSX/SheetJS, Git, GitHub e Vercel.

O projeto ainda está em evolução. Os próximos passos são autenticação real, banco de dados, painel administrativo, upload de fotos, dashboards mais completos e integração futura com processos de PCM.

Esse projeto faz parte do meu portfólio de desenvolvimento web aplicado à manutenção industrial, confiabilidade e gestão de ativos.
